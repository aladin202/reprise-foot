# Reprise Foot — PWA
Application d'entraînement sans équipement, bilan de match, poids et progression adaptative.

## Publication
Dans GitHub : Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Installation Android
Ouvrir https://aladin202.github.io/reprise-foot/ dans Chrome puis ⋮ → Ajouter à l'écran d'accueil / Installer.

## Données
Les données sont stockées dans le navigateur, pas dans GitHub. Depuis la V4 locale, exporter la sauvegarde JSON (Paramètres), puis l'importer sur le nouveau site. Ne jamais ajouter les sauvegardes au dépôt. Les données ne sont pas synchronisées entre appareils.

## Hors ligne
Après la première ouverture en ligne, le service worker conserve le contenu en cache. Le navigateur peut néanmoins effacer ses données; effectuer des exports réguliers.
